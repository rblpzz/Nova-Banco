NOVA — PWA (aplicación web instalable)

CONTENIDO
- index.html: aplicación NOVA completa (estilos y lógica incluidos).
- manifest.webmanifest: nombre, iconos y modo de pantalla independiente.
- service-worker.js: caché básica para abrir la app sin conexión después de la primera carga.
- icons/: iconos propios de NOVA.

IMPORTANTE
Para instalar como PWA, los archivos deben estar publicados en una dirección HTTPS. Abrir index.html directamente desde Descargas NO permite instalar una PWA ni activar el service worker.

PUBLICACIÓN SENCILLA
Puedes subir el contenido de esta carpeta a un repositorio de GitHub y activar Settings > Pages > Deploy from a branch > main > /(root). Cuando GitHub Pages publique la dirección HTTPS, ábrela en Chrome en tu Samsung, menú ⋮ > Añadir a pantalla de inicio / Instalar aplicación.

La aplicación es una simulación educativa. No conecta con bancos ni procesa dinero real. No uses contraseñas reales. Los datos se guardan en el almacenamiento local del navegador.
